## La page d'accueil de Cinando

Cinando est une plateforme professionnelle de l'industrie du cinéma. J'ai refait sa page d'accueil et ses outils fonctionnels à partir de maquettes Photoshop, en travaillant directement sur le site Joomla en place.

## Animations de scroll sur une base existante

La difficulté tenait à l'existant : le nouveau style devait cohabiter avec le CSS de l'ancien site sans le casser. J'ai découpé les maquettes, puis ajouté en JavaScript les animations de scroll et les effets sur les images demandés pour cette page.
